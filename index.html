DigiFarm UI Guidelines v1.7
Design system for all client-facing demos and internal tools. All components use the same tokens — dark, satellite-first aesthetic with agricultural green as the primary action color.

Changelog

v1.7
Version 1.7 (Sep 21, 2026)
  • Added Selectable Cards; fixed Avatar's neutral status styling and switched the User Card example to medium-size avatars.
  • Added the Avatar component — sizes, no-color/neutral variant, status indicators, avatar groups, hover-to-reveal name, and a User Card example.
  • Added the Calendar component — single date, date range, and two-month range pickers.
Version 1.6 (Sep 21, 2026)
  • Added Segmented Control, Loaders, and Draggable Cards components.
  • Table: two-line field cells, updated status badges, an anchored row-actions dropdown, and a sortable Area column.
  • Badges & Tags: added a small size, removed status dots, added a Pending (grey) status, and renamed Beta → In Progress, Processing → Review.
Version 1.5 (Sep 21, 2026)
  • Added Illustrations and Partners blocks; Partners now carries 20+ logos with light/dark variants, reordered light-first.
  • Simplified the Login header to the wordmark only, added icon-less Alert variants, and reworked Input with Label to a label-top / input-bottom, three-state (default, focused, error) pattern.
  • Polish: full-width Country Flags grid, square favicon (no radius), and the Dropdown label no longer shows a required asterisk.
Version 1.4 (Aug 28, 2026)
  • Added Radio and Checkbox components, and an Illustrations block.
  • Redesigned Alerts with five semantic variants (neutral, info, warning, error, success), circular icon badges, and icon-less variants.
  • Replaced the Login / Registration block with the real access-code + email sign-in flow, including the request-account modal.
Version 1.3 (Aug 28, 2026)
  • Added Table and Tooltip components.
  • Fixed Dropdown item hover behavior — bold weight is now reserved for the active/selected item only.
  • Expanded the Icon Library to the full 2,267-icon Remix Icon set, organized into 17 searchable categories.
Version 1.2 (Aug 27, 2026)
  • Added the Partners block with light and dark logo variants.
  • Restored full sidebar navigation with section links.
  • Added the Logo section (wordmark and favicon reference sizes) and the Buttons with Icons block.
Version 1.1 (Aug 27, 2026)
  • Added the Changelog card and the Download HTML export button.
  • Simplified sidebar navigation to a flat list, removing category labels.
Version 1.0 (Aug 27, 2026)
  • Initial release — Foundation (colors, typography, spacing, flags), Components (buttons, inputs, badges, cards, alerts), Patterns (map UI elements, CSS variables), and core Blocks (Crop Classification, Productivity Zones, Time Series, Field Sustainability Index).
